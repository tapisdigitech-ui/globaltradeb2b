# Prioritised Launch Checklist

Source: `docs/ROUND10A_INDEPENDENT_AUDIT.md` (finding ids F-x refer to it). Nothing here has been implemented; no migration or proposal was applied or edited. "Migration?" means a new migration would be needed (historical migrations and the baseline are never edited). Evidence label per finding: **C** confirmed by probe on the local PG17.11 replica, **K** read from the final catalogue, **S** static reading, **N** needs the real stack.

Severity rule used: P0 = must be settled before any hosted validation run; P1 = required before real supplier/buyer onboarding; P2 = can follow launch. Theoretical issues are labelled as such and not counted as vulnerabilities.
